# Мережева система виявлення вторгнень (NIDS) на базі Suricata

[![Suricata](https://img.shields.io/badge/IDS-Suricata%207.0-red.svg)](https://suricata.io/)
[![Platform](https://img.shields.io/badge/Platform-Ubuntu%20Server%2022.04-orange.svg)](https://ubuntu.com/)
[![Switching](https://img.shields.io/badge/Cisco-SPAN%20Mirroring-blue.svg)](https://cisco.com/)
[![Python](https://img.shields.io/badge/Python-3.10%2B-yellow.svg)](https://python.org/)
[![License](https://img.shields.io/badge/License-MIT-lightgrey.svg)](LICENSE)

Практична реалізація системи виявлення мережевих аномалій та кібератак для захисту корпоративної комп'ютерної інфраструктури. Проєкт базується на високопродуктивному аналізаторі пакетів **Suricata**, технології апаратного дзеркалювання трафіку **Cisco SPAN** та кастомізованій базі сигнатур для детекції мережевого сканування, підбору паролів, DoS-атак та веб-експлуатацій.

> **Курсова робота з дисципліни:** «Комп'ютерні системи і мережі»  
> **Освітньо-професійна програма:** «Комп'ютерна інженерія» (Спеціальність 123)  
> **Заклад освіти:** ВСП «Ірпінський фаховий коледж НУБіП України»  
> **Керівник:** викладач Кумейко В. О.

## Топологія

Сенсор підключено в пасивному режимі (Out-of-band) до моніторингового порту комутатора ядра, що гарантує захист мережі без внесення затримок та без створення єдиної точки відмови:
